# Checklist obrigatório

Use antes de publicar uma peça, aprovar uma interface ou enviar trabalho a um fornecedor. “Não se aplica” precisa ser justificável.

## A. Marca e conteúdo

- [ ] O material pertence a pelo menos um dos quatro pilares: Busca, Interpretação, Transitividade ou Letramento crítico.
- [ ] O território de entrada é identificável.
- [ ] Toda afirmação técnica tem fonte rastreável.
- [ ] O racional aparece; a peça não entrega apenas conclusão/conduta.
- [ ] Grau de certeza e limitações estão explícitos quando relevantes.
- [ ] Jargão foi definido na primeira aparição.
- [ ] Não há promessa de transformação, resultado garantido ou linguagem de guru.
- [ ] Não há ataque nominal a pessoa, profissão, marca ou instituição.
- [ ] Se há ironia, ela ocorre no máximo uma vez e recai sobre ideia/prática/argumento.
- [ ] Material público não tem assinatura individual.
- [ ] A peça termina com pergunta, tarefa ou próximo passo quando o formato comporta.
- [ ] Alguém que não produziu o material fez a revisão final.

## B. Cor

- [ ] O fundo claro é Pink Essence por padrão.
- [ ] A composição respeita a dominância aproximada 58% Pink Essence / 28% Dark Amaranth / 7% Classic Crimson / 5% Debian Red / até 2% Crimson Violet.
- [ ] Crimson Violet não foi usado como fundo padrão, cabeçalho, navegação, CTA primário, texto corrido, borda padrão ou primeira série de gráfico.
- [ ] Há apenas um vermelho de acento por peça: Classic Crimson OU Debian Red.
- [ ] Nenhuma cor nova foi criada fora dos tokens aprovados.
- [ ] Não há gradiente.
- [ ] Classic Crimson/Debian Red não são usados como texto corrido sobre Pink Essence.
- [ ] Contraste foi validado para o tamanho real do texto/controle.
- [ ] Estado não depende somente de cor.

## C. Tipografia

- [ ] Source Serif Pro é usada para display/editorial.
- [ ] Inter é usada para interface e leitura longa.
- [ ] IBM Plex Mono está restrita a dado/rótulo técnico/tabela.
- [ ] Não há Source Serif 4 usada como substituta canônica.
- [ ] Texto corrido está alinhado à esquerda.
- [ ] Corpo não foi reduzido para caber.
- [ ] Linha de leitura não ultrapassa aproximadamente 68ch.

## D. Logo

- [ ] O arquivo oficial foi usado.
- [ ] O wordmark foi preferido quando há espaço.
- [ ] O ponto final está presente.
- [ ] A área de proteção equivalente à altura do “I” foi preservada.
- [ ] Wordmark tem pelo menos 90px no digital; símbolo, 32px.
- [ ] Não houve distorção, recoloração, sombra, contorno, brilho, gradiente, rotação ou recriação.
- [ ] O fundo oferece contraste suficiente.

## E. Layout

- [ ] Hierarquia é construída por espaço, tipografia, borda e cor chapada.
- [ ] Cards/painéis não receberam arredondamento genérico.
- [ ] Sombras decorativas não foram usadas.
- [ ] Existe respiro suficiente entre grupos semânticos.
- [ ] A grade não força leitura excessivamente larga.
- [ ] A interface foi testada primeiro/explicitamente em mobile.
- [ ] Nada essencial depende de hover.

## F. Imagem e dados

- [ ] Cada imagem informa/documenta algo; não está ali só para “decorar”.
- [ ] Textura, se usada, é subordinada e não reduz contraste.
- [ ] Ícones são simples, monocromáticos e não carregam significado sozinhos quando ambíguos.
- [ ] Gráfico apresenta eixo, unidade, período e fonte.
- [ ] Gráfico não usa 3D/gradiente nem eixo enganoso.
- [ ] Incerteza é mostrada quando faz parte do dado.
- [ ] Tabela tem cabeçalhos adequados e números alinhados coerentemente.

## G. Acessibilidade e interação

- [ ] Texto normal atinge WCAG AA 4,5:1.
- [ ] Texto grande/elemento gráfico relevante atinge ao menos 3:1 quando aplicável.
- [ ] O foco por teclado é visível.
- [ ] Ordem de foco segue a ordem de leitura.
- [ ] Controles têm nome acessível.
- [ ] Alvos interativos são, em regra, pelo menos 44×44px.
- [ ] Erros têm mensagem, não só cor.
- [ ] Motion tokens são centralizados e não há ramificações de movimento por dispositivo.
- [ ] Zoom de 200% preserva uso principal.
- [ ] Imagens informativas têm alt; imagens realmente decorativas têm alt vazio.
- [ ] Conteúdo dinâmico importante é anunciado de maneira acessível.

## H. Código

- [ ] Novos componentes usam tokens semânticos, não hex espalhado.
- [ ] Nenhuma classe/token academy-* foi copiada como referência visual.
- [ ] Não há linear-gradient, radial-gradient ou conic-gradient.
- [ ] Logo não foi reconstruída em JSX/CSS.
- [ ] Variante nova tem razão semântica documentada.
- [ ] Mudança de contrato atualiza DECISIONS/CHANGELOG/tokens na mesma alteração.

## Gate final

Se qualquer item obrigatório falha, o material não está pronto. Corrigir antes de publicar; não “compensar” a quebra com uma exceção visual informal.
