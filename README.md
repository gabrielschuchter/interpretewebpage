# Gabriel Schuchter

Site pessoal para apresentar acompanhamento nutricional, o Interprete. e o Nutriwork.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Rotas

- `/` — seleção inicial de caminho
- `/home` — Home editorial da marca pessoal
- `/acompanhamento-nutricional` — serviço clínico
- `/interprete` — aulas individuais em Prática Baseada em Evidências

Os tokens visuais foram derivados de `gabriel-schuchter-design-system/design-system/tokens.css`. Os CTAs de agendamento direcionam ao WhatsApp oficial; o e-mail exibido é `schuchtergabriel@gmail.com`.
